## Key Website Sections & Features

1. **Cinematic Hero**: Fluid typography, responsive layout, and full-resolution interactive showreel modal.
2. **About FloZ**: Studio background, philosophy, and three pillar values (*Our Approach*, *What Drives Us*, *What We Value*).
3. **Services**: Full service showcase across 7 disciplines:
   - Product Design
   - Web Design & Development
   - UX/UI Design
   - Brand Identity
   - Mobile Engineering
   - Digital Products
   - Branding & Visual Direction
4. **Core Engineering Capabilities**: Interactive categorized filter cards highlighting stack expertise across Frontend & Mobile, Cloud & Backend, AI & Automation, and Systems Architecture.
5. **Leadership Team Showcase**: Bruno-inspired editorial portrait carousel with 100% monochrome studio treatment, unified neural background matting, dynamic slide counters (`01 / 05`), and touch-friendly dot pagination.
6. **FAQ Accordion**: Expandable interactive accordion covering pricing, timelines, modernizations, technical planning, and client communication.
7. **Contact & Community Outro**: Direct connection channels including Discord 24/7 developer hub and studio email contacts.

## Local Development & Setup

### Prerequisites
- Node.js (v18+) or Python (v3.8+)

### Running the Website

Using npm scripts:
```bash
# Start local server on http://localhost:8000
npm run dev
# or
npm start
```

Or using Python directly:
```bash
python3 serve.py 8000
```

Visit [http://localhost:8000](http://localhost:8000) in your browser.

## Responsive Design & Breakpoints

The website is engineered with zero horizontal overflow across all major device categories:

- **360px** — Small Mobile (Compact Android)
- **390px** — Standard Mobile (iPhone 12/13/14/15)
- **430px** — Large Mobile (iPhone Pro Max, Plus)
- **768px** — Tablet (iPad portrait)
- **1024px** — Small Laptop / Tablet landscape
- **1366px** — Standard Desktop
- **1920px** — Large Desktop / Widescreen displays
